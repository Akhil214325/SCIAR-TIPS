How the current rule works

Each week's card tips form one pool. Points are awarded for hours before 23:00: floor manager 1.5 points/hour; server and bar 1 point/hour; chef 0.5 points/hour; kitchen porter 0.25 points/hour. A payout is the weekly pool multiplied by an employee's points and divided by all points that week. The owner sets the rule.

The current rule excludes hours after 23:00. This dashboard makes that effect visible; it does not decide whether the rule is fair.
